How does detection and resolution work?

Actions

  • Keep & Del Rest: keeps this comic and permanently deletes all others in the group.
  • Keep: advances this comic. If only one other comic remains pending, it is auto-kept too and the group resolves.
  • Re-Q: removes from this group and sends back to Imported for re-scraping.
  • Del: permanently deletes this comic's file and record from disk.
  • Keep All: marks all comics as intentional. Use for false positives.

Detection methods

CV IDTwo comics share the same ComicVine issue ID.
Series / NumberSame series name, issue number, and volume year.
Cover HashCover images compared by pHash Hamming distance. Distance 0 = identical.
FilenameOS-generated duplicate files with appended suffix.
