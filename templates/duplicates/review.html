How does detection and resolution work?

Actions

  • Keep & Del Rest: keeps this comic and permanently deletes all others in the group.
  • Keep: advances this comic. If only one other comic remains pending, it is auto-kept too and the group resolves. To explicitly discard others, use Del or Re-Q on them first.
  • Re-Q: removes from this group and sends back to Imported for re-scraping.
  • Del: permanently deletes this comic's file and record from disk.
  • Keep All: marks all comics as intentional. Use this for false positives.

Detection methods

CV ID
Two comics share the same ComicVine issue ID. Most reliable — both were scraped to the exact same CV issue. One digital + one physical of the same issue is never flagged.
Series / Number
Same series name, issue number, and volume year. Catches unscraped duplicates. Skipped if page counts differ by more than 3x (prevents TPBs matching single issues) or if it's a single digital + physical pair.
Cover Hash
Cover images compared by pHash Hamming distance (default threshold: 5 bits, adjustable under Settings › Deduplication). Distance 0 = identical. The Distance column shows how similar each cover is to the group anchor.
Filename
OS-generated duplicate files where the OS appended a suffix: file_1.cbz / file (1).cbz. At least one file in the group must carry the suffix.
