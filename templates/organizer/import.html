About .lop Files

The .lop (Library Organizer Profile) file is an XML format used by ComicRack to define how comics should be organized into folders. Each profile contains:

  • Folder and file templates with placeholders
  • Matching rules to determine which comics use this profile
  • Character replacement mappings for filesystem safety
  • Month name mappings for date formatting
